# 模板 · 项目适配表

> 版本 v1.0｜2026-10-19｜适用范围：所有项目｜上位文件：README（十条铁律）

**用法**：复制本表到项目根目录，命名为《项目适配表》，逐项填写后与通用规范一并声明为必读。**通用规范 + 本表 = 该项目可执行的完整规范**；未填写的项按通用规范的默认值执行，不得留空后自行发挥。

**三条填写纪律**：①"填写值"列必须是可判定的具体值或命令，不得写"视情况"；②本表只能**加严**（提高阈值、增加检查、缩短周期），凡放宽必须在表 D 登记；③每次修改在表 E 追加一行，不覆盖旧行。
